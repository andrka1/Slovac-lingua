# Lingua Mini Slovak — исправленная версия 2.1

Эта версия сделана **не как новый интерфейс**, а непосредственно из присланного `Lingua-main (3).zip`. Сохранены исходные React-компоненты, тёмное оформление, градиентные кнопки и нижняя навигация. Английские учебные данные заменены словацкими. Озвучки нет.

## Открыть без сборки

Откройте `Lingua-Mini-Slovak.html` в браузере. Это готовая автономная версия: учебные данные, CSS и JavaScript находятся внутри файла. На телефоне HTML может открываться в файловом просмотрщике — используйте полноценный браузер, веб-версию или Android-сборку. На некоторых браузерах хранение прогресса для локальных файлов нестабильно; делайте резервную копию.

## Что осталось от оригинала

- Главная страница, оригинальные кнопки «Карточки», «Квиз», «Письмо», «Грамматика».
- Четыре пункта нижней навигации, исходные иконки и мобильная ширина.
- Переворот карточек, свайпы, стрелки, отметка «Знаю», скрытие слов, фильтры «Все / Новые / Выученные».
- Квиз с четырьмя вариантами, выбором категории и количеством вопросов, режимами «Новые / Ошибки / Все».
- Письмо: ввод по русскому переводу, подсказка, пропуск, проверка, повтор слабых слов. Добавлены кнопки словацкой диакритики.
- Грамматические упражнения с выбором формы в пропуск, объяснением и подсветкой правильного/неправильного ответа.
- Определение времени предложения.
- Таблица форм глаголов, тест на формы и ручной ввод двух форм.
- Конструктор предложений из перемешанных слов.
- Слова-исключения, редактор своих слов и категорий, импорт/экспорт слов, скрытие и восстановление.
- Исходные экраны статистики и настроек.

В исходном архиве были готовые, но не подключённые экраны «Найди пары» и «Прогресс». Здесь они доступны с главной страницы. «Найди пары» не выбирает две карточки с одинаковым русским переводом в одном раунде, чтобы ответ не был неоднозначным.

## Что заменено и добавлено

- 1000 уникальных словацких слов и словосочетаний: 500 A1, 350 A2, 150 B1, 20 тем. Уровни ориентировочные, не официальные списки CEFR.
- 129 готовых фраз в 11 ситуациях. Фразы участвуют в исходных карточках, квизе и письме через категорию «Готовые фразы». Всего в общей колоде 1129 единиц плюс свои слова.
- Кириллическая подсказка чтения. `:` означает долготу, а не ударение. Русская запись приблизительная, не IPA: она не покрывает все исключения и контекстные уподобления. H условно обозначается «г», но словацкий звук — звонкий гортанный [ɦ].
- Алфавит из 46 букв, названия и звуки с русскими пояснениями, примеры.
- Пошаговый курс: 25 уроков, теория, примеры, таблицы и упражнения. Урок отмечается пройденным при 80% и выше.
- 25 тем с 254 вопросами и упражнениями. Среди тем: 6 падежей и 12 моделей существительных, род и число, прилагательные, местоимения, предлоги, спряжение, возвратность, модальность, время и даты, прошедшее/будущее, вид, условное/повелительное, сравнение, вуз.
- 3 словацких времени; 68 упражнений в разделе времён; 36 предложений для конструктора. Часть упражнений времён повторяет профильные вопросы курса.
- 30 глаголов: инфинитив, форма ja и прошедшая форма для on; тест и ручной ввод. У совершенных глаголов форма ja обозначает будущее, что поясняется в интерфейсе. Английских V2/V3 и 12 английских времён нет.
- 10 особых форм множественного числа.
- Числа 0–9999, дата и цифровая форма времени.
- Разговорник для магазина, транспорта, врача, жилья, документов и учёбы в вузе.

Конструктор проверяет заданный нейтральный образец, а не все возможные словацкие порядки слов. Первое слово показано как подсказка; интерфейс предупреждает, что другие порядки тоже могут быть допустимы.

Материалы — учебный конспект основных тем A1–A2, а не полный академический справочник. Все 1000 единиц не проходили профессиональную лингвистическую редактуру. Для уточнения произношения и сложных форм используйте словарь, преподавателя и проверенный курс. Это не полный курс B1/B2 и не сертификат.

Источники для сверки основных правил:
- https://slovake.eu/grammar/pronunciation
- https://slovake.eu/grammar/classes/verbs
- https://slovake.eu/grammar/classes/noun

## Прогресс и перенос

Ключи хранения начинаются с `lingua_slovak_original`. Прогресс английского оригинала и предыдущей переработанной версии не переносится автоматически: у них другие наборы карточек и форматы.

Настройки → «Создать резервную копию» сохраняет прогресс упражнений, пройденные уроки, свои слова и категории. Для восстановления вставьте этот текст в поле и подтвердите замену. Резервная копия — не облачная синхронизация. Сброс прогресса не удаляет свои слова и категории, как и в оригинале.

## Обновить GitHub-проект

Лучше использовать **новый репозиторий**, чтобы не смешать старый переработанный проект с оригинальным стеком. Загрузите содержимое папки `Lingua-Slovak-Original` так, чтобы `package.json`, `src`, `index.html` и `.github` находились в корне репозитория.

Если обновляете прежний репозиторий, замените проект целиком, особенно `package.json`, `package-lock.json`, `index.html`, `src`, `scripts`, `vite.config.ts`, `tsconfig.json`, `tailwind.config.js`, `postcss.config.js`, `capacitor.config.ts` и workflow. Не переносите старую сгенерированную папку `android`: конфигурация нового приложения создаётся заново. `node_modules` загружать не нужно.

Если GitHub не даёт загрузить `.github`, создайте файл через Add file → Create new file, полный путь `.github/workflows/android.yml`, вставьте содержимое файла из этого архива. Сохраните отступы.

Android workflow исправлен: Java 17 и явные SDK-пакеты вместо удалённого `tools`. Запускайте новый workflow после сохранения изменений, а не повтор старого запуска.

## Локальная веб-сборка

Node.js 20+:

```bash
npm ci
npm run dev
```

Для готовой сборки:

```bash
npm run build
npm run preview -- --host
```

Production-сборка создаёт каталог `dist`, service worker и автономный `Lingua-Mini-Slovak.html`. TypeScript проверяется перед Vite-сборкой. Предупреждение Vite о JS-файле более 500 КБ не является ошибкой: словарь и теория встроены для офлайн-работы.

Разместите `dist` на HTTPS для установки веб-приложения на главный экран. После первого успешного открытия приложение кэшируется. Для локального HTML установка PWA не предусмотрена. При новой сборке номер кэша меняется автоматически.

## Android APK

В GitHub: Actions → Build Android APK → Run workflow. После успешной сборки скачайте артефакт **Lingua-Mini-Slovak-APK**; внутри будет `app-debug.apk`.

APK в архив не включён. Android workflow подготовлен, но не запускался в GitHub в рамках этой проверки. Если возникнет ошибка, нужны последние строки журнала упавшего шага.

Для локальной Android-сборки нужны JDK 17, Android Studio и SDK:

```bash
npm ci
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

Идентификатор приложения: `com.linguamini.slovak`. Это отдельное приложение, не обновление английской установки. Для магазина потребуется отдельная release-подпись. Ключей подписи в проекте нет.
