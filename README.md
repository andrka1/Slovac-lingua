# Slovak Lingua — словацкий с нуля

Переделка присланного Lingua Mini для русскоговорящего человека, который готовится учиться в Словакии. Формат оригинала сохранён: React, карточки, тесты, письмо и локальные данные. Английские материалы и экраны заменены словацкими; учебный интерфейс переработан. Озвучки, записи голоса и микрофона нет.

## Самый простой запуск — без установки

1. Распакуйте ZIP.
2. Откройте `Slovak-Lingua.html` в современном браузере (Chrome, Edge, Firefox).
3. Начните с «Курс с нуля» или «Алфавит».

HTML содержит код и учебные данные внутри: после скачивания интернет не нужен. На некоторых телефонах файловый менеджер открывает HTML в просмотрщике вместо полноценного браузера. Тогда используйте размещённую веб-версию или соберите Android APK по инструкции ниже. Поведение localStorage для локальных файлов зависит от браузера; для надёжного хранения предпочтительны приложение, localhost или сайт. Не переименовывайте и не перемещайте локальный HTML без резервной копии: браузер может считать его другим приложением.

## Что встроено

- Ровно 1000 уникальных слов и словосочетаний (20 тематических групп по 50). A1: 500, A2: 350, B1: 150. Эти уровни — редакционные ориентиры, не утверждённые официальные списки CEFR.
- Русский перевод и автоматическая кириллическая подсказка чтения каждого слова и фразы. Для части частых исключений есть ручные поправки.
- Алфавит из 46 букв: звук, русская запись названия буквы и пример. Объяснения долготы, ударения, дифтонгов и слоговых r/l.
- 25 последовательных уроков, теория и примеры, 52 вопроса в итоговых тестах уроков. Чтобы завершить урок, нужно не менее 80%. Все уроки открыты для самостоятельного выбора.
- Подробный конспект основных тем A1–A2: род, число, местоимения, прилагательные, 6 падежей, 12 моделей существительных в единственном и множественном числе, спряжения, настоящее / прошедшее / будущее, вид, возвратность, модальность, повелительное и условное наклонение, сравнение, связки.
- 129 фраз в 11 ситуациях: знакомство, магазин, ресторан, транспорт, врач, экстренная помощь, поступление, занятия, жильё, документы, повседневные дела.
- Числа 0–9999, чтение выбранной даты и цифровая форма времени.
- Карточки, тест на перевод и письмо, фильтры темы/уровня, избранное, свои слова с редактированием транскрипции.
- Скрытие слов без потери данных и восстановление скрытых слов в настройках.
- Светлая/тёмная/системная тема, дневная цель и экспорт/импорт прогресса JSON.

## Как учиться

Урок 1 → правила чтения → примеры → тест → слова к уроку → 10 карточек. Потом следующий урок. Используйте набор «Повторить» в тренировках, чтобы видеть новые слова и слова, срок повторения которых наступил. Дневная цель считает слова, впервые отмеченные как известные; повторение не увеличивает счётчик новых слов.

### Повторение

«Знаю» повышает ступень карточки и назначает следующий просмотр через 1, 3, 7, 14 или 30 дней. «Повторить» сбрасывает ступень и делает слово доступным сегодня. Это простой интервальный алгоритм, не SM-2. Баллы тестов сохраняются отдельно; тест не меняет отметку «изучено». Сессия содержит до 10 случайно выбранных слов текущего набора.

### Важно о транскрипции

Русские буквы не передают все словацкие звуки. `:` обозначает долготу, не ударение. H условно записывается «г», хотя это звонкий гортанный [ɦ]. Автоматическая запись отражает основные правила, но может не учитывать исключения заимствований, все уподобления в связной речи и особенности мягкости. Важные исключения нужно сверять с носителем или преподавателем. Транскрипция — стартовая подсказка, а не точная IPA-запись.

Материалы составлены специально для приложения. Для сверки алфавита и основных грамматических правил использовались разделы Slovake.eu:
- https://slovake.eu/grammar/pronunciation
- https://slovake.eu/grammar/classes/verbs
- https://slovake.eu/grammar/classes/noun

Это учебный конспект, не исчерпывающая академическая грамматика. Словарь B1 помогает перейти к учебной лексике, но приложение не является полным курсом B1 и не выдаёт сертификат. Для поступления уточняйте требования конкретного вуза; юридических инструкций и актуальных сроков подачи документов здесь нет.

## Сохранение и перенос

Все данные хранятся на устройстве в localStorage под отдельным ключом `slovak_lingua_progress_v1`. Старый английский прогресс не переносится, чтобы не спутать идентификаторы слов. Пользовательские слова получают id от 10001. В «Настройках» экспортируйте JSON до удаления данных браузера. Импорт заменяет текущие данные и требует подтверждения. Это не облачная синхронизация.

## Исходники и сборка

Нужны Node.js 20+ и npm. Установка зависимостей требует интернета:

```bash
npm install
npm run build
npm run dev
```

Откройте http://localhost:3000. Сервер раздаёт готовый каталог `dist`; после изменения кода снова выполните `npm run build` и обновите страницу. Сборка создаёт автономный HTML и веб-каталог `dist`.

- `src/App.jsx` — интерфейс и работа с прогрессом.
- `src/data/lexicon.txt` — 1000 пар слово/перевод и тематические группы.
- `src/data/phrases.txt` — разговорник.
- `src/data/course.js` — теория, таблицы, примеры, вопросы.
- `src/data/phonetics.js` — кириллическая подсказка и алфавит.
- `scripts/data.cjs` — проверка размера и уникальности словаря, генерация данных.
- `scripts/build.cjs` — production-сборка в один файл через esbuild.

Не редактируйте `compiled.js` напрямую: он пересоздаётся из текстовых словарей. HTML в архиве уже собран, npm для его открытия не нужен.

## Веб-приложение и офлайн-установка

Разместите содержимое `dist` на HTTPS-сайте. После первого успешного открытия service worker кэширует приложение для офлайн-работы. Chrome/Edge на Android поддерживают «Добавить на главный экран» / «Установить приложение». В iOS используйте Safari → «Поделиться» → «На экран Домой». Из файла `file://` PWA не устанавливается. Для новой публикации измените версию кэша в `public/sw.js`, иначе старая установка может продолжать показывать предыдущую версию.

## Как собрать Android APK

APK в этот архив не включён. Приложение подготовлено для Capacitor 6; Android-сборка в текущей среде не запускалась.

### Через GitHub Actions

1. Создайте репозиторий и загрузите содержимое папки проекта (так, чтобы package.json и .github находились в корне).
2. Откройте Actions → Build Android APK → Run workflow.
3. После успешной сборки скачайте артефакт `Slovak-Lingua-debug-APK` и распакуйте `app-debug.apk`.
4. На Android разрешите установку из того источника, откуда открываете APK. Это debug-сборка, не релиз для магазина.

Workflow использует внешние сервисы и требует доступного GitHub Actions. Он подготовлен, но не проверен запуском в GitHub.

### Локально

Установите Android Studio, Android SDK и JDK 21:

```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

В Android Studio дождитесь синхронизации Gradle и соберите APK. Для публикации в Google Play нужна отдельная настройка подписи и release-сборка. Никакие ключи подписи в проект не включены.
